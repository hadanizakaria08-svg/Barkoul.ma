# حالة المنصات

هذه الوثيقة تصف ما هو موجود فعلياً في فرع `rebuild/unified-platform`، لا ما نخطط لإضافته لاحقاً.

| المنصة | الموجود حالياً | ما لم يُنجز بعد |
|---|---|---|
| Web | تطبيق React/TypeScript مع مسار بناء مخصص باستخدام esbuild، وواجهة عربية RTL | مطابقة مخطط Supabase الحي، اختبارات تكامل حقيقية للبيانات والمصادقة، واستكمال الوظائف التجارية |
| PWA | ملف manifest وService Worker مكتوبان يدوياً؛ يخزن بعض الأصول الثابتة ويوفر نسخة من صفحة البداية عند انقطاع الاتصال | اختبار التثبيت والعمل دون اتصال والتحديث على أجهزة ومتصفحات فعلية، واختبارات آلية لدورة حياة Service Worker |
| Android | اعتماديات Capacitor الأساسية وملف `capacitor.config.ts` موجودة | مجلد Android الأصلي غير مولّد بعد؛ يلزم إنشاء المنصة عبر Capacitor ثم المزامنة والبناء واختبار APK على جهاز |
| iOS | اعتماديات Capacitor الأساسية وملف الإعداد المشترك موجودان | مجلد iOS الأصلي غير مولّد بعد؛ يلزم إنشاء المنصة عبر Capacitor ثم البناء في macOS/Xcode واختبار جهاز فعلي |
| Windows | هيكل Tauri 2 موجود، بما فيه إعداد Cargo وملفات Rust وتهيئة نافذة التطبيق | بناء Windows فعلي، والتحقق من المثبّت والتشغيل والتحديث والتوقيع قبل أي توزيع |

## الاختبارات الآلية الموجودة

- GitHub Actions يشغّل فحص TypeScript، واختبارات domain، وبناء الويب.
- يتضمن CI اختبار Playwright للواجهة الأساسية، وحالة النشر للزائر، وتسميات الحقول، وعرض الهاتف، وفحصاً آلياً أولياً لإمكانية الوصول باستخدام axe.
- نجاح هذه الفحوص يثبت اجتياز السيناريوهات الموجودة فقط؛ ولا يثبت اكتمال المنتج أو مطابقة قاعدة البيانات الحية أو سلامة جميع تدفقات المستخدم.

## ما لم يتم إثباته بعد

- لا توجد في المستودع أدلة على ملفات APK أو IPA أو EXE نهائية ومختبرة.
- لم يُثبت تشغيل التطبيق مع مشروع Supabase الإنتاجي، ولم تُنفّذ اختبارات تكامل على بيئة Supabase منفصلة.
- لم تُختبر عمليات التفاوض والرحلات وتوثيق السائق والعمولات والمدفوعات ولوحة الإدارة كمسارات متكاملة.
- لم يُثبت التثبيت والعمل دون اتصال والتحديث الآمن على أجهزة فعلية.

## بوابة الاعتماد

لا تُعلن أي منصة مكتملة قبل نجاح اختبارات البناء والوظائف والأمان والتشغيل على بيئة أو جهاز مناسب. لا تُنفّذ migrations على قاعدة الإنتاج، ولا تدمج إلى `main`، ولا تنشر أي إصدار دون موافقة صاحب المشروع.
