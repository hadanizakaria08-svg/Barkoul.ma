# Barkoul.ma — نموذج التهديدات الأولي

## الأصول المطلوب حمايتها
حسابات المستخدمين، أرقام الهواتف والبيانات الشخصية، تفاصيل الشحنات، وثائق السائقين، عروض التفاوض، سجلات الرحلات، سجلات الإدارة، وأي بيانات مالية.

## مصادر التهديد
- مستخدم يحاول قراءة أو تعديل بيانات مستخدم آخر.
- مستخدم يرفع دوره إلى admin أو يزور ملكية سجل.
- سائق/مالك يحاول تغيير حالة شحنة أو تفاوض خارج المسار المسموح.
- طلبات مكررة أو متزامنة تسبب تكرار رحلة أو عمولة.
- XSS عبر العناوين والملاحظات وبيانات المستخدم.
- سرقة جلسة أو إساءة استخدام جهاز مشترك.
- ملفات مرفوعة خبيثة أو أكبر من المسموح.
- تسريب مفاتيح أو رموز في المستودع أو سجلات الأخطاء.
- إساءة استخدام API أو محاولات تخمين كلمات المرور.

## الضوابط المطلوبة
- RLS على كل جدول مكشوف للعميل مع اختبارات سلبية وإيجابية لكل دور.
- تحقق خادمي من الملكية والحالة، مع قيود ومعاملات ذرية.
- عدم كشف بيانات الاتصال إلا وفق قاعدة عمل موثقة.
- عدم وجود service_role أو أسرار في كود المتصفح.
- ترميز النصوص عند العرض، والتحقق من المدخلات، وتقييد معدل العمليات الحساسة.
- جلسات آمنة، تسجيل خروج واضح، وعدم حفظ كلمات المرور محلياً.
- فحص الملفات والتحقق من الحجم والنوع والمالك.
- سجلات تدقيق لا تحتوي على أسرار، وخطة استجابة واستعادة.
- اختبارات للطلبات المتكررة، التلاعب بالمعرفات، وتبديل الأدوار.

## خارج النطاق حالياً
لا يوجد اعتماد أمني أو اختبار اختراق مكتمل. هذه قائمة تهديدات وضوابط مطلوبة وليست شهادة بأن التطبيق آمن.
