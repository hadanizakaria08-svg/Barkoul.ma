# حالة المنصات

| المنصة | الحالة | ما يلزم |
|---|---|---|
| Web | أساس React/Vite موجود | إعداد متغيرات Supabase، مطابقة البيانات، اختبار شامل |
| PWA | لم تُفعّل بعد | manifest، service worker، اختبار التثبيت والتحديث |
| Android | إعداد Capacitor أولي | تثبيت CLI/platform، بناء واختبار جهاز حقيقي |
| iOS | إعداد Capacitor أولي | جهاز/بيئة macOS وأدوات Apple، مراجعة متطلبات المتجر |
| Windows | مخطط عبر Tauri | إعداد Rust/Tauri وبناء وتوقيع واختبار Windows |

لا توجد حالياً ملفات APK أو IPA أو EXE جاهزة، ولا يتم الادعاء بأن أي منصة أُطلقت.
