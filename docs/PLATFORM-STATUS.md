# حالة المنصات

| المنصة | الحالة الفعلية في المستودع | ما يلزم قبل الاعتماد |
|---|---|---|
| Web | تطبيق React/Vite موجود، مع إعداد Supabase عبر متغيرات البيئة | مطابقة مخطط البيانات الحي، إعداد بيئة اختبار، واختبارات وظيفية شاملة |
| PWA | إعداد VitePWA وmanifest وservice worker موجود في إعداد البناء | التحقق من التثبيت والعمل دون اتصال وسلوك التحديث على متصفحات وأجهزة فعلية |
| Android | إعداد Capacitor الأساسي موجود | توليد مشروع Android ومزامنة الإضافات والبناء واختبار APK على جهاز فعلي |
| iOS | إعداد Capacitor الأساسي موجود | يلزم بناء عبر بيئة macOS/Xcode واختبار على جهاز فعلي ومراجعة متطلبات المتجر |
| Windows | هيكل Tauri موجود ضمن apps/desktop | استكمال إعداد Rust/Tauri والبناء والتوقيع واختبار EXE على Windows |

## ما لم يتم إثباته بعد

- لا توجد في هذا المستودع حالياً أدلة على ملفات APK أو IPA أو EXE نهائية ومختبرة.
- وجود إعداد PWA أو Capacitor أو Tauri لا يعني أن التطبيق اجتاز اختباراً على جهاز فعلي أو أصبح جاهزاً للنشر.
- نجاح CI يتحقق من typecheck والاختبارات الحالية والبناء، ولا يثبت اكتمال الوظائف التجارية أو تكامل Supabase.

## بوابة الاعتماد

لا يُعلن عن أي منصة على أنها مكتملة قبل نجاح اختبارات البناء والوظائف والأمان والتشغيل على بيئة أو جهاز مناسب، مع الحفاظ على عدم النشر أو الدمج إلى main دون موافقة صاحب المشروع.
