## اختبار قاعدة البيانات المتكامل

في 20 نوفمبر 2026 نُفّذت اختبارات تكاملية محاكاة داخل معاملات PostgreSQL ثم أُلغيت كل المعاملات بالكامل (ROLLBACK). استخدمت حسابات اصطناعية مؤقتة، ولم تُحفظ أي حسابات أو شحنات أو وثائق أو رحلات أو عمولات اختبارية في الإنتاج.

شملت الاختبارات:
- إنشاء profile تلقائي لحساب Auth جديد، وإنشاء شحنة بصلاحيات المالك.
- منع تعديل/حذف الشحنة مباشرة ومنع تصعيد الدور.
- تسجيل وثيقة سائق مرتبطة بكائن موجود، ثم مراجعتها من المدير.
- منع عرض بسعر صفر، وإنشاء عرض صحيح، وقبول العرض.
- إظهار بيانات الطرف الآخر للمشاركين فقط.
- انتقال الرحلة إلى loading ثم in_transit ثم delivered.
- إلغاء رحلة بعد التحميل، وإعادة فتح الشحنة، ثم قبول عرض جديد وإنشاء رحلة بديلة مع الاحتفاظ بسجل الرحلة الملغاة.
- إنشاء عمولتي 10 و20 درهماً، وتسجيل تحصيل نقدي وإلكتروني تجريبي.
- طلب ترقية دور وموافقة المدير، والتحقق من عزل سجل التدقيق.
- محاكاة سياسة حذف التخزين: منع حذف الوثيقة الموثقة والسماح بتنظيف وثيقة pending.

نجحت الاختبارات المحاكاة، وتأكد الفحص اللاحق من أن سجلات الاختبار المؤقتة أُزيلت بالـROLLBACK. هذا لا يعادل اختبار تسجيل الدخول الفعلي أو إرسال البريد أو استخدام Storage REST API من المتصفح.

## قاعدة البيانات والإطلاق

- سجل الإنتاج يحتوي على 19 migration، وملف migration الخاص بصلاحيات سير العمل وRPCs محفوظ في المستودع.
- تم إصلاح profile المستخدم القديم الذي يملك شحنة، وإسناد دور `owner` له؛ لم تُمنح أي صلاحية admin جديدة.
- بقيت البيانات التجارية الحالية كما هي: شحنة واحدة، ولا توجد وثائق أو عروض أو رحلات أو عمولات.
- Health advisor بلا تحذيرات. Security advisor لا يعرض lints؛ بقي تحذير Leaked Password Protection لأنه غير متاح في خطة Supabase Free. تحذيرات الفهارس غير المستخدمة معلوماتية ولم تُحذف.
- لا يوجد مزود دفع إلكتروني مربوط؛ التحصيل الإلكتروني الحالي تسجيل مرجع خارجي من المدير.
- لا يوجد تمرين backup/restore موثق حتى الآن.
- لم تُجرَ اختبارات تسجيل حقيقية أو Storage REST API بحسابات مستخدمين منفصلة.

## شروط إعلان الجاهزية النهائية

لا تُعلن جاهزية المتاجر قبل اختبار Android وWindows وiOS على أجهزة فعلية، وإضافة مفاتيح التوقيع المطلوبة، واختبار Auth وStorage عبر واجهاتها الحقيقية، وتنفيذ backup/restore، وربط مزود دفع إذا تقرر استخدامه.
