# Barkoul.ma

منصة مغربية لربط أصحاب البضائع بسائقي الشاحنات.

## الحالة الحالية
- التطبيق الموحد React/TypeScript موجود في `main` واجتاز فحوصات CI.
- تم تطبيق تدقيق صلاحيات قاعدة البيانات والإصلاحات الأخيرة على Supabase الإنتاجية.
- ملف `index.html` القديم محفوظ كنسخة رجوع.
- الواجهة الجديدة لم تُنشر بعد على GitHub Pages؛ النشر الأول يتطلب ضبط Pages على **GitHub Actions** ثم تشغيل سير عمل النشر اليدوي.

## المتطلبات
- Node.js 20+
- npm 10+

## تشغيل الواجهة
1. انسخ `.env.example` إلى `.env`.
2. ضع Supabase URL ومفتاح Publishable/anon العام فقط في متغيرات البيئة.
3. شغّل `npm install`.
4. شغّل `npm run dev`.

## الفحوصات
- `npm run typecheck`
- `npm test`
- `npm run build`
- `npm run test:e2e`

## الأمان
لا تضع مفتاح `service_role` أو أي سر في الواجهة أو المستودع. يعتمد الوصول على RLS والتحقق الخادمي. تغييرات قاعدة البيانات يجب أن تكون عبر migrations مراجعة ومختبرة.

## المنصات
الويب هو المنصة التي تم بناءها وفحصها آلياً. Capacitor وTauri موجودان كأساس مشترك، لكن حزم Android/iOS/Windows لم تُبنَ أو تُختبر على أجهزة فعلية بعد.
