# Barkoul.ma

منصة مغربية لربط أصحاب البضائع بسائقي الشاحنات.

## حالة التطوير
التطوير الجديد يجري في الفرع `rebuild/unified-platform` ولا يغير الموقع المنشور أو قاعدة البيانات الحية.

## المتطلبات
- Node.js 20+
- npm 10+

## تشغيل الواجهة
1. انسخ `.env.example` إلى `.env`.
2. ضع Supabase URL وPublishable/anon key العام فقط في متغيرات البيئة.
3. شغّل `npm install`.
4. شغّل `npm run dev`.

## فحوصات
- `npm run typecheck`
- `npm test`
- `npm run build`

## الأمان
لا تضع مفتاح service_role أو أي سر في الواجهة أو المستودع. يعتمد الوصول الآمن على RLS والتحقق الخادمي. لا تنفذ migrations على الإنتاج من دون مراجعة وموافقة.

## المنصات
الواجهة الحالية أساس مشترك للويب. إعداد Capacitor وTauri يأتي بعد اكتمال مطابقة البيانات والاختبارات الأساسية.
